## 🎯 New Framework Overview

### **DDTF (Deep Diagnostic Test Framework)**

**Key Principles**:
1. **Visibility First** - Show exact input prompts and responses
2. **Persistence** - Store every test run with version history
3. **Demo-Ready** - Fully explainable for live demonstrations
4. **Workflow-Driven** - Linear, guided testing process
5. **Agent-Centric** - Deep integration with Agent Catalog

---

## 📋 13 Core Requirements

1. ✅ **Agent Testing** - Full framework with UI, backend, analytics
2. ✅ **DDTF Workflow** - Linear 7-step guided process
3. ✅ **Test Input Visibility** - Show exact prompts (CRITICAL)
4. ✅ **Results Persistence** - Store with version history
