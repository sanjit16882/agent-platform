# DDTF Quick Start Guide

## 🎯 What is DDTF?

**Deep Diagnostic Test Framework** - A comprehensive agent testing system with:
- Full input visibility (see exact prompts)
- Guided 7-step workflow
- Version tracking and comparison
- Agent Catalog integration
- Demo-ready transparency

---
